# Resilience Gate v1.1.0 — observability and evidence

**Released:** 4 October 2026

[GitHub release](https://github.com/devSatym/resilience-gate/releases/tag/v1.1.0)
· [Changes since v1.0.0](https://github.com/devSatym/resilience-gate/compare/v1.0.0...v1.1.0)

This release packages the latest source, focused observability and reviewed
evidence presentation. It is a backward-compatible repository/platform
milestone, not a newly published application image or a new live testnet run.

## Highlights

- Apache 2.0 licensing and a project attribution notice, explicitly selected
  by the owner. Third-party components retain their existing licences.
- Four focused Grafana dashboards cover application traffic, payments/signer
  readiness, Kubernetes runtime and chaos-gate evidence. Wallet readiness is
  grouped by privacy-safe wallet index.
- GKE kube-dns monitoring uses the sidecar metrics endpoint. Dashboard payment
  metrics and gate-log selectors match the implemented contracts; application
  restarts are distinguished from dependency failure and recovery.
- 34 reviewed screenshots, hash/caption manifest, original architecture
  illustrations and a visual README lead into exact verification records.
- Offline documentation validation checks local links, screenshot integrity
  and deterministic accessible SVG artwork.
- Repository discovery, security reporting, issue forms and current CI/release
  entry points accompany the source release.

## Deployment and evidence status

The owned GCP lab was retired on **4 October 2026**. Screenshots and records
are historical; there is no active deployment. Google-managed recovery records
remain subject to the dates in the [retirement receipt](../lab-retirement.md).

`prod` means **production-like owned testnet**. This release makes no mainnet,
public-production, high-availability, custody, disaster-recovery or independently
audited supply-chain claim. See the [known limitations](../known-limitations.md).

The release's evidence ZIP contains selected tracked public documentation and
images only. Its SHA-256 checksum supports download integrity, not signing or
independent attestation. Source archives are provided separately by GitHub.
